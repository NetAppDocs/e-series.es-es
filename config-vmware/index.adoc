= Guía de inicio rápido para la configuración del host VMware en E-Series
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
El método VMware express para instalar tu matriz de almacenamiento y acceder a SANtricity System Manager es adecuado para configurar un host VMware independiente con un sistema de almacenamiento E-Series. Está diseñado para poner en marcha el sistema de almacenamiento lo más rápido posible, con un mínimo de decisiones que tomar.



[[procedure-overview]]
== Descripción general del procedimiento

El método Express incluye los siguientes pasos, que también se describen en el link:understand-vmware-workflow-concept.html["Flujo de trabajo de VMware"].

. Configure uno de los siguientes entornos de comunicación:
+
** link:nvme-fc-perform-specific-task.html["NVMe over Fibre Channel"]
** link:fc-perform-specific-task.html["Fibre Channel (FCP)"]
** link:iscsi-perform-specific-task.html["ISCSI"]
** link:sas-perform-specific-task.html["SAS"]
** link:nvme-roce-perform-specific-task.html["NVMe over roce"]
** link:nvme-tcp-perform-specific-task.html["NVMe sobre TCP"]


. Crear volúmenes lógicos en la cabina de almacenamiento.
. Hacer que los volúmenes estén disponibles para el host de datos.
