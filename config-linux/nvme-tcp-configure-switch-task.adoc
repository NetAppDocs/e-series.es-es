= Configura los conmutadores para hosts NVMe over TCP con Linux de E-Series
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Configura los conmutadores siguiendo las recomendaciones del fabricante para NVMe sobre TCP. Estas recomendaciones pueden incluir tanto directrices de configuración como actualizaciones de código.

E-Series no ofrece instrucciones específicas sobre la configuración de red. Consulta a tu administrador de red para que te oriente sobre cómo seleccionar la configuración adecuada para tu entorno.
